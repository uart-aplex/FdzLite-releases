## Installation

Requires Android 6.0 or later and Android System WebView. Download the APK on your Android device and allow installation from the browser or file manager when prompted. This is a debug-signed sideload build, not a Google Play release. It can update the existing FdzLite 0.1.6 test installation signed with the same certificate.
